# Rivet provenance

Forge vendors and customizes the browser application from
[Ironclad Rivet](https://github.com/Ironclad/rivet) under Rivet's MIT license.

- Upstream snapshot: `7cdd13a1beec16d86004768da4866500d259647a`
- Forge distribution surface: `packages/core`, `packages/trivet`, and `packages/app`
- Forge changes: native API bridge defaults, Forge branding/theme, embedded-app shell,
  dependency hardening, and release-bundle integration
- License text: [`LICENSE`](LICENSE)

The upstream license notice remains in the source tree and is copied into every
packaged `Forge.app` at `Contents/Resources/ThirdPartyLicenses/Rivet-MIT.txt`.
